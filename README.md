# Infiltration
The application allows obstacles to be placed on an X/Y coordinate grid, which is then used to generate a navigable map. Users can visualise the generated map or select a starting point and destination to calculate the shortest available path between them.

## Features
+ Generate maps using user-defined X/Y coordinates and obstacles
+ Visualise generated maps on a grid
+ Select a starting point and destination
+ Calculate the shortest path between two points
+ Handle obstacles and unavailable grid locations
+ Interactive map generation and pathfinding

## Technologies Used
+ C#
+ Grid-based data structures
+ Pathfinding algorithms
  
## Project Context
Developed independently as a Uni project. The project focused on applying programming, algorithm design, data structures, and problem-solving concepts to a practical pathfinding application.
